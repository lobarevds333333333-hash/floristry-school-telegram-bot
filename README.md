# 💐 Telegram-бот «Бот школы флористики» (Цветочные Истории)

Telegram-бот для онлайн-школы флористики, разработанный на Python 3.10+ с использованием фреймворка **aiogram 3.x**. Бот предназначен для консультирования клиентов о курсах школы, предоставления акций, отправки PDF-каталога и биографии основателя, а также сбора заявок с валидацией данных, генерацией уникального номера (#FL-XXXX), POST-интеграцией с CRM (Битрикс24 / Webhook) и мгновенным уведомлением администратора.

---

## 📌 Основной функционал

1. **Главное меню (`/start`):**
   - Текст приветствия согласно ТЗ.
   - Меню: `О школе`, `Каталог курсов`, `Акции`, `Пробный урок`, `Контакты`.
2. **О школе:**
   - Биография основателя и брендированная карточка-фотография (`founder.jpg`).
3. **Каталог курсов:**
   - Выгрузка брендированного PDF-файла каталога (`catalog.pdf`).
   - Inline-просмотр программ обучения (стоимость, длительность, описание) и кнопка «Записаться».
4. **Акции:**
   - Спецпредложения и кнопка записи на бесплатный урок.
5. **Пробный урок и Запись на курс (FSM-форма):**
   - Валидация формата телефона (регулярные выражения: `+7...`, `8...`).
   - Валидация E-mail формата (`name@domain.com`).
   - Сохранение в базу данных SQLite с присвоением уникального кода заявки (`#FL-1001`).
   - POST-запрос в CRM-систему (Битрикс24 или Custom Webhook) с обработкой ошибок.
   - Уведомление администратора/менеджера в Telegram.
   - Подтверждение пользователю с уникальным номером заявки.
6. **Контакты:**
   - Адрес, телефон, e-mail, режим работы и ссылки на соцсети.

## 🛠 Быстрый запуск

### 1. Клонирование и установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка файла окружения `.env`
Создайте файл `.env` (или скопируйте из `.env.example`):
```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
ADMIN_CHAT_ID=123456789
CRM_WEBHOOK_URL=http://127.0.0.1:8000/api/lead
DB_PATH=bot_database.db
```

* **`BOT_TOKEN`**: Токен вашего бота от [@BotFather](https://t.me/BotFather).
* **`ADMIN_CHAT_ID`**: Ваш Telegram ID (узнать можно у [@userinfobot](https://t.me/userinfobot)).
* **`CRM_WEBHOOK_URL`**: URL для отправки POST-запросов (Битрикс24 REST API или тестовый `http://127.0.0.1:8000/api/lead`).

### 3. Интеграция с Битрикс24 (настройка)
Для интеграции с Битрикс24 укажите Webhook URL в `.env`:
```env
CRM_WEBHOOK_URL=https://your_subdomain.bitrix24.ru/rest/1/your_webhook_token/crm.lead.add.json
```
Бот автоматически распознает REST API Битрикс24 и сформирует корректную структуру полей (`TITLE`, `NAME`, `PHONE`, `EMAIL`, `COMMENTS`).

### 4. Запуск локального эмулятора CRM (для тестирования)
В отдельном окне терминала запустите тестовый сервер CRM:
```bash
python mock_crm.py
```
Сервер будет принимать POST-запросы от бота на `http://127.0.0.1:8000/api/lead` и выводить данные лидов в консоль.

### 5. Запуск бота
```bash
python main.py
```
При первом запуске бот автоматически сгенерирует файл `assets/catalog.pdf` и фото основателя `assets/founder.jpg`, а также инициализирует базу данных SQLite `bot_database.db`.
